# Instruction

## Backend

In order to start the application you can place with terminal in the Backend folder and type 

```
dotnet build 
```

and after

```
dotnet run
```

The backend starts on port 5000 and you will see swagger UI at http://localhost:5000/swagger/index.html


## Frontend

Move with terminal in Frontend folder.

So type 

```
npm run dev
```

the application starts on port 10000

http://localhost:10000/
